# Vox Protocol

`cargo test --locked` проверяет бинарный контракт сигнализации.

Один бинарный WS message содержит 19-байтовый заголовок big-endian
и одно значение postcard. Порядок полей заголовка: major (u16), minor (u16),
kind (u16), flags (u8), request ID (u64), длина тела (u32).
Размер тела ограничен 256 КиБ. Транспорт также ограничивает размер
собранного сообщения до декодирования. Бит 0 отмечает обязательный
вид сообщения. Неизвестный необязательный вид можно пропустить.

Коды kind и порядок вариантов перечислений закреплены в src/lib.rs.
Клиент начинает соединение с ClientHello, сервер отвечает ServerHello
или ProtocolError. Поддержка frame E2EE обязательна. Формат кадра
сигнализации не определяет формат шифрования медиа.

Сервер с CAP_SFU_TRANSPORT принимает AttachMedia на WSS из RoomJoined.
Он проверяет билет и generation, затем возвращает SdpAnswer. Клиент
может отправлять ICE candidates после ответа. Ответ на IceCandidate и
GetTransportState — TransportState для этого соединения. Connected
указывает готовность ICE/DTLS. E2EE требует отдельной проверки на клиентах.
